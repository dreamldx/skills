# skills

Personal agent skills, installable with [`npx skills`](https://github.com/vercel-labs/skills).

```
npx skills add dreamldx/skills -g -y
```

Install a single skill:

```
npx skills add dreamldx/skills --skill playwright-edge-windows -g -y
```

## Skills

- **google-flights-scraper**: scrape flight prices and options from Google Flights with Playwright.
- **playwright-edge-windows**: drive headless Microsoft Edge with Playwright on Windows.
